# DeloreanSHOP

Tienda en línea de DMC-12 personalizados (Time Machine, clásicos, custom).
React + Vite + Tailwind CSS. Pedidos por WhatsApp.

    npm install
    npm run dev      # desarrollo
    npm run build    # compila a dist/ para publicar (Netlify)

Cambia el número de WhatsApp en `src/components/FormularioPedido.jsx`.
Tienda ficticia con fines formativos (SENA · ADSO).
